Show the codecraft quick reference. One shot, change nothing: do not switch mode, write flag files, or persist anything. Levels: /codecraft lite (build what's asked, name the lazier alternative in one line), /codecraft (full, the default ladder: YAGNI then stdlib then native then one line then minimum), /codecraft ultra (deletion before addition, challenges the requirement before building). Commands: /codecraft-review (over-engineering review of the current changes), /codecraft-audit (whole-repo over-engineering audit), /codecraft-debt (harvest shortcut: comments into a tracked ledger), /codecraft-gain (measured-impact scoreboard from the benchmark), /codecraft-help (this card). Deactivate with 'stop codecraft', 'normal mode', or /codecraft off; resume anytime with /codecraft. Default mode is full; change it with the CODECRAFT_DEFAULT_MODE environment variable (off|lite|full|ultra) or a config file at ~/.config/codecraft/config.json (Windows: %APPDATA%\codecraft\config.json) with {"defaultMode": "lite"}. Resolution order: env var, then config file, then full.
