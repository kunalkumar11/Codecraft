The upstream npm scope and repository URLs still name their original owner. This local derivative should not be published through that package identity or represented as an official upstream release. The GitHub publish workflow is restricted to the canonical upstream repository; a public CodeCraft package requires a maintainer-owned npm scope and repository URL.
